Autonomy Logic OpenPLC Runtimeにおける未認証管理者作成の脆弱性（CVE-2026-126088）

要約

CISAはオープンソースのプログラマブルロジックコントローラ実行環境「Autonomy Logic OpenPLC Runtime」の脆弱性を発表しました。バージョン4.2.4以下が影響を受け、未認証の攻撃者によって複数の管理者アカウントが作成されるリスクがあります。これにより、産業制御システムに対する完全な管理権限の掌握につながる可能性があります。

根拠（収集時の抜粋）
OpenPLC Runtime <=4.2.4 (CVE-2026-126088) において未認証で複数の管理者アカウントを作成可能とCISAが公表。

実務上の示唆

Web/APIインターフェースの認証・認可バイパスに関する典型的な脆弱性であり、ブラックボックス診断やDASTでの検出対象となり得ます。PLC制御を行うインターフェースに対して未認証で特権操作が実行できる状態は重大であり、ネットワーク分離だけでなく製品自体の根本的な認証機構の検証が必要です。診断業務では管理機能のエンドポイントに対するアクセス制御検証シナリオを強化する必要があります。

重要度判定の理由

産業用制御環境において未認証での管理者権限奪取が可能となる極めて危険な脆弱性であるため。
